# Badge Mode-swap prototype

Throwaway UI prototype for the Wayfinder ticket “Prototype the Badge Mode-swap confirmation.”

Run it from the repository root:

```sh
python3 -m http.server 4173 --directory Prototypes/BadgeModeSwap
```

Then open <http://localhost:4173/?variant=A>. Use the floating switcher or the left/right arrow keys to compare variants.
