# Stats hierarchy prototype

> THROWAWAY PROTOTYPE — this is a visual decision aid, not production code.

Question: Does the approved four-metric strip above a full-width Monthly
activity calendar feel clear, balanced, and recognizably FoldWise at native
window sizes in both Light and Dark appearances?

Run it with one command from the repository root:

```sh
./Prototypes/StatsHierarchy/run.sh
```

Use the bottom review bar to compare three structural treatments, switch
between 880×640, 980×720, and 1180×760 windows, and force Light or Dark.
Left and right arrow keys cycle the treatments.

The sample activity intensity is deliberately illustrative. Thresholds,
legend language, day-detail copy, and interaction/accessibility behavior belong
to later Wayfinder decisions and are not settled by this prototype.
